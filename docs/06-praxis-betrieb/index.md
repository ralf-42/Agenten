# Praxis & Betrieb
{: .no_toc }

Diese Orientierungsseite führt vom lauffähigen Prototyp zum betreibbaren Agentensystem. Dazu gehören Infrastruktur, das Zusammenspiel der Frameworks, Projektstruktur, Deployment, das zusammengeführte Praxisprojekt des PMO-Assistenten und der Provider-Wechsel. Im Mittelpunkt stehen Meeting-Vorbereitung, Dokumentenaufbereitung, Aufgabenverfolgung sowie quellengebundene Briefings und Statusübersichten; verbindliche Projektentscheidungen bleiben beim Menschen.
