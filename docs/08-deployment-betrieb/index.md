# Deployment & Betrieb

Diese Orientierungsseite führt vom lauffähigen Prototyp zum betreibbaren Agentensystem. Dazu gehören Infrastruktur, Projektstruktur, Deployment, Provider-Wechsel und das zusammengeführte Praxisprojekt des PMO-Assistenten.
