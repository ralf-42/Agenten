Agent Harness: Die 3-Schichten-Kontrollarchitektur

          

            Ein Harness umschließt das LLM mit Information Layer (Kontext, Memory, Tool-Schemas),
            Execution Layer (Plan, Tool-Ausführung, Guardrails) und Feedback Layer
            (Schema-Prüfung, Human-in-the-Loop, Rückspeicherung ins Memory). Teste den Unterschied zwischen erstem Lauf und zweitem Lauf nach einer Korrektur!
          

        

      


      

        

          

            
            
            
            
            
          

          

            
            
          

        

        

      


      

        

          

            Schicht 1
            
Information Layer

            Bereit
          

          
Kontext-Assembly, relevante Datensätze, Langzeit-Memory und progressive Tool-Schemas.

          

        


        

          

            Schicht 2
            
Execution Layer

            Bereit
          

          
Agent Loop: Planen → Tool-Aufruf → Policy-/Guardrail-Gate → Retry oder Abschluss.

          

        


        

          

            Schicht 3
            
Feedback Layer

            Bereit
          

          
Schema-Validierung, menschliche Korrektur und Speicherung als Regel im Memory für künftige Läufe.

Loop Engineering: 12 Techniken für verlässliche Agentenschleifen

          

            Jeder Agent-Loop folgt dem Zyklus Inspect → Act → Verify → Decide → Repeat.
            Schalte einzelne Schutztechniken gezielt an oder aus und beobachte in vier typischen Fehler-Szenarien,
            welche Technik den Lauf rettet — und was passiert, wenn sie fehlt.
