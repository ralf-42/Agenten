④ Welche Module auswählen?

Die Wahl der Target Modules hängt von drei Faktoren ab:

🧠 Was lernen die Module?
Attention (Q, K, V, O)
Beziehungen zwischen Tokens
Welche Wörter zusammengehören, Kontext verstehen, Syntax
FFN (W_up, W_down)
Faktenwissen & Domänenwissen
Gespeicherte Fakten, fachspezifisches Vokabular, Weltwissen
🎯 Aufgaben-Komplexität
Einfach
Sentiment, Klassifikation, NER
→ Q, V reichen meist
Mittel
Summarization, QA, Translation
→ Q, K, V, O
Komplex
Code, Reasoning, neue Domäne
→ Alle + höherer Rank
📊 Empirische Erkenntnisse
✓ Q + V zusammen ist oft am effektivsten (Original-Paper)
~ K allein bringt wenig Verbesserung
✓ Rank erhöhen ist oft besser als mehr Module
~ FFN hilft bei Domänenadaption (neues Faktenwissen)
🔀 Entscheidungsbaum
Start: Was ist dein Ziel?
Stil/Ton anpassen
↓
Q, V (r=8-16)
Attention steuert "wie" geschrieben wird
Besseres Reasoning
↓
Q, K, V, O (r=16-32)
Komplexere Attention-Muster
Neue Domäne/Fakten
↓
Alle + FFN (r=32-64)
FFN speichert Faktenwissen
💡 Praktische Vorgehensweise
1 Starte minimal: Q, V mit r=8
2 Evaluiere: Ist die Performance ausreichend?
3 Skaliere hoch: Erst Rank erhöhen (r=16, 32), dann Module hinzufügen
4 FFN nur wenn nötig: Bei Domänenwissen oder wenn Attention allein nicht reicht
⚖️ Tradeoff
Mehr Module = mehr Parameter = mehr VRAM = längeres Training
Aber: LoRA ist so effizient, dass man oft "großzügig" sein kann
